## 📚 Curriculum Overview

### Module 1: Python Basics (Level 0)
* Introduction to Python & Setup (VS Code, Jupyter, Virtual Envs)
* Variables, Data Types & Operators
* Conditional Statements (`if`, `elif`, `else`)
* Loops (`for`, `while`) & Control Flow (`break`, `continue`, `pass`)

### Module 2: Core Data Structures
* Working with Lists, Tuples, Sets, and Dictionaries
* List & Dictionary Comprehensions
* String Manipulation & Methods

### Module 3: Functions & Modular Coding
* Defining Functions, Arguments (`*args`, `**kwargs`)
* Lambda Functions & Built-in Functions (`map`, `filter`, `reduce`)
* Modules, Packages, and `pip` Management

### Module 4: Object-Oriented Programming (OOP)
* Classes, Objects, and `__init__`
* Inheritance, Encapsulation, and Polymorphism
* Magic/Dunder Methods (`__str__`, `__repr__`, etc.)

### Module 5: Advanced Python
* Decorators & Generators
* Exception Handling (`try`, `except`, `finally`, Custom Exceptions)
* File Handling & Working with JSON/CSV
* Context Managers (`with` statement)
* Multithreading, Multiprocessing & `asyncio`
